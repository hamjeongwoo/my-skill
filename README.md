# my-skill

내가 만든 Claude Code 스킬을 모아 관리하는 저장소.

## 구조

```
.claude/skills/<스킬이름>/SKILL.md
```

스킬 하나가 폴더 하나. 각 폴더의 `SKILL.md` 가 스킬 본문이다.

## 스킬 목록

| 스킬 | 하는 일 |
|---|---|
| `addtask` | 작업 지시를 할 일 문서(`docs/TODO.md`)에 일감으로 추가하고 상태·진행 기록을 관리한다. 완료는 `docs/DONE.md` 로 옮긴다 |
| `stay` | 자리에 있는지(채팅)·비웠는지(텔레그램 ask 봇)를 전환한다 |

## 다른 프로젝트에서 쓰기

프로젝트의 `.claude/skills/` 아래에 원하는 스킬 폴더를 복사하거나 심볼릭 링크한다.
